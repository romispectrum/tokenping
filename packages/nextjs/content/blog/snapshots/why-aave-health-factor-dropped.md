Behaviour claims checked in source code (aave-dao/aave-price-feeds `main`, file unchanged against the fact-sheet copy on 2026-10-14):
`PriceCapAdapterStable.latestAnswer()` returns the cap when the feed is above it, 0 when the feed is ≤ 0, and the feed's own answer
otherwise, so any price below $1 passes through. `setPriceCap` is callable by the risk admin or pool admin, so the cap can change.
https://github.com/aave-dao/aave-price-feeds/blob/main/src/contracts/PriceCapAdapterStable.sol

Other code facts used (aave-v3-origin `main`, fetched 2026-10-14): `GenericLogic.calculateUserAccountData` reads `getAssetPrice` for
every asset on each call and returns `type(uint256).max` with no debt; `ValidationLogic.validateLiquidationCall` (local copy
`aave-raw/ValidationLogic.sol` lines 263-279) requires the two reserves of that call, the collateral being seized and the debt being
repaid, to be active and not paused, plus an expired grace period on both, and does not check frozen. So a pause blocks liquidations
that use the paused asset; liquidations of other unpaused collateral/debt pairs in the same position stay possible; `validateSupply` and `validateBorrow` reject frozen
reserves; supply, withdraw, borrow, repay and liquidation all reject paused reserves. v3.1 docs: grace period after unpause, capped by
`MAX_GRACE_PERIOD` (4 hours, fact sheet §4.1). v3.7 isolated E-Mode doc: outside collateral becomes LTV-zero, "liquidation threshold is
unaffected".

## Worked arithmetic (recomputed by the writer with Python, 2026-10-14)

Example A: 10 WETH at an illustrative $2,400, LT 83%, 12,000 USDC debt.

- HF = 24,000 × 0.83 ÷ 12,000 = 1.66. ETH −10% ($2,160): 1.494 → "1.49". ETH −20% ($1,920): 1.328 → "1.33".
- Liquidation price = 12,000 ÷ (10 × 0.83) = $1,445.78 (−39.76% → "39.8%").
- Interest, one year, rates from block 26193378 held constant, ETH flat: debt 12,000 × e^0.04496 = 12,551.8 (simple 12,539.5)
  → "about 12,550 USDC"; collateral 10 × e^0.01309 = 10.1318 WETH (simple 10.1309) → "about 10.13"; HF 1.6079 (simple 1.6094) → "about 1.61".
- Hypothetical LT cuts: 82% → 1.64; 80% → 1.60.
- USDC as debt: USDC $0.88 → 19,920 ÷ 10,560 = 1.886 → "about 1.89"; USDC valued at the $1.04 cap → 19,920 ÷ 12,480 = 1.596 → "about 1.60".

Example C: 10,000 USDC collateral, LT 78%, 2.5 WETH debt at an illustrative $2,400 ($6,000).

- HF = 7,800 ÷ 6,000 = 1.30. ETH +10% ($2,640): 7,800 ÷ 6,600 = 1.1818 → "1.18". HF = 1 at ETH = 7,800 ÷ 2.5 = $3,120 (+30%).
- USDC $0.88: 8,800 × 0.78 ÷ 6,000 = 1.144 → "1.14". HF = 1 at USDC = 6,000 ÷ 7,800 = $0.7692 → "about $0.77".
- Interest, one year, USDC supply 3.800% vs WETH borrow 1.943%: HF 1.3244 (simple 1.3237) → "about 1.32".

E-Mode: HF at max borrow = 95 ÷ 93 = 1.0215 → "≈ 1.02", below the 1.0288 line from the March 2026 post-mortem.
Rule used in Cause 3: with one collateral and one debt asset at constant prices, HF(t) = HF(0) × (growth of collateral) ÷ (growth of
debt), so HF falls exactly when the debt's borrow rate exceeds the collateral's supply rate.

## Tokenping facts used (product.md, code on branch feat/blog-seo, 2026-10-14)

Checks every 5 minutes (`vercel.json`, `NOTIFICATION_CHECK_INTERVAL_MINUTES`); since 2026-10-16 every Aave V3 market on 21 networks (24 markets, Ethereum's four included, Harmony left out) and every Aave V4 Spoke (Ethereum, Avalanche, Arc, Base), so 22 networks in all; before that day 7 networks, Ethereum Core pool only
(`config/aaveConfig.ts`); Signal or email (articles name these two only, per the build spec; superseded 2026-10-20: Signal, Telegram or email, see the update at the end); threshold 1.1-10
(`constants/notifications.ts`); alerts repeat on every check while below the threshold and there is no recovery message
(`services/notifications/runNotificationCheck.ts`); they stop when HF recovers or the config is deleted (product.md §4.3), and editing (the article's "lower the threshold") or
deleting a config requires active paid access (product.md §5.4). The article does not say that alerts continue after expiry (§5.4/§11). The alert price is not in the article body; the page template's end box reads it
on-chain.
