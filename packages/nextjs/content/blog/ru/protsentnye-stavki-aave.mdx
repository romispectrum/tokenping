## Что определяет ставку по займу на Aave?

На Aave V3 ставку по займу актива определяют две вещи: его коэффициент использования и параметры процентной ставки. Коэффициент использования показывает, какая доля пула актива выдана в долг: долг, делённый на сумму долга и токенов, которые ещё доступны. Параметры: четыре числа для каждого актива, которые задаёт governance Aave, а Risk Stewards Aave могут менять их ограниченными шагами и не чаще минимальных интервалов:

- **Оптимальный коэффициент использования (optimal usage ratio):** использование, при котором кривая делает излом.
- **Базовая ставка (base rate):** ставка по займу при использовании 0 %.
- **Slope 1:** насколько растёт ставка от 0 % до оптимального коэффициента использования.
- **Slope 2:** насколько ещё она растёт от оптимального коэффициента использования до 100 %.

По данным на 25 октября 2026 г., в блоке Ethereum 26269328 и блоке Arbitrum 518125419, параметры и ставки нескольких популярных активов были такими:

| Рынок и актив      | Оптимальное использование | База  | Slope 1 | Slope 2 | Использование   | APR займа | APR вклада |
| ------------------ | ------------------------- | ----- | ------- | ------- | --------------- | --------- | ---------- |
| Ethereum Core USDC | 94 %                      | 0 %   | 4,5 %   | 10 %    | 93,72 %         | 4,49 %    | 3,78 %     |
| Ethereum Core USDT | 92 %                      | 0 %   | 4,5 %   | 10 %    | 87,81 %         | 4,30 %    | 3,39 %     |
| Ethereum Core WETH | 92 %                      | 0 %   | 2,2 %   | 6 %     | 81,31 %         | 1,94 %    | 1,31 %     |
| Ethereum Core GHO  | 99 %                      | 4,5 % | 0 %     | 0 %     | не используется | 4,50 %    | 0 %        |
| Arbitrum USDC      | 90 %                      | 0 %   | 4 %     | 10 %    | 77,32 %         | 3,44 %    | 2,39 %     |

Исключение составляет GHO: оба его наклона равны нулю, поэтому его ставка не меняется при любом использовании, а меняют её вручную (см. [GHO и Aave V4](#как-устанавливаются-ставки-для-gho-и-на-aave-v4)).

## Как рассчитывается ставка по займу на Aave?

Ставка по займу в Aave V3 представляет собой прямую линию до оптимального коэффициента использования и гораздо более крутую линию выше него. Если обозначить использование через U:

**До оптимального коэффициента использования: ставка по займу = база + slope 1 × U ÷ оптимальный коэффициент использования**

**Выше него: ставка по займу = база + slope 1 + slope 2 × (U − оптимальный коэффициент использования) ÷ (1 − оптимальный коэффициент использования)**

В контракте U равно общему долгу, делённому на сумму общего долга и токенов, которые ещё остаются в пуле. С параметрами USDC на Ethereum Core ставка при каждом уровне использования такова:

| Использование  | APR займа |
| -------------- | --------- |
| 50 %           | 2,39 %    |
| 80 %           | 3,83 %    |
| 90 %           | 4,31 %    |
| 94 % (оптимум) | 4,50 %    |
| 95 %           | 6,17 %    |
| 96 %           | 7,83 %    |
| 98 %           | 11,17 %   |
| 100 %          | 14,50 %   |

Ниже 94 % десять пунктов использования сдвигают ставку меньше чем на полпункта. Выше каждый пункт добавляет около 1,67 пункта, а последние шесть пунктов использования более чем утраивают ставку. По данным на 25 октября 2026 г. использование USDC составляло 93,72 %, чуть ниже излома: 4,5 % × 0,9372 ÷ 0,94 дают те самые 4,49 %, которые тогда платили заёмщики.

Кривая так и задумана. Ниже оптимального уровня дешёвые займы поддерживают пул в работе; выше крутая ставка делает заём настолько дорогим, что часть заёмщиков погашает долг, а часть держателей вносит токены, это возвращает использование вниз и оставляет токены для вкладчиков, которые хотят их вывести.

## Почему ставки по займам на Aave резко растут?

Ставки по займам на Aave резко растут, когда использование переходит оптимальный коэффициент, обычно потому, что крупный вкладчик выводит средства или крупный заёмщик берёт заём. Ставка пересчитывается в той же транзакции, и каждый заёмщик этого актива платит новую ставку с этого момента до следующего изменения.

14 октября 2026 г. один вывод ровно 133 898 000 USDC из Ethereum Core поднял использование с 93,92 % до 99,50 % в одном блоке:

| Блок Ethereum (UTC)             | Что произошло                              | Использование | APR займа USDC |
| ------------------------------- | ------------------------------------------ | ------------- | -------------- |
| 26194052 (14 октября, 23:32:47) | До вывода                                  | 93,92 %       | 4,50 %         |
| 26194053 (14 октября, 23:32:59) | Выведено 133 898 000 USDC                  | 99,50 %       | 13,67 %        |
| 26194088 (14 октября, 23:39:59) | Максимум за этот период                    | около 99,8 %  | 14,18 %        |
| 26194231 (15 октября, 00:08:35) | Тот же адрес внёс 133 898 000 USDC обратно | 94,16 %       | 4,76 %         |

Заёмщики 36 минут платили примерно втрое больше обычной ставки, и формула выше воспроизводит каждую из этих ставок по использованию. Скачок длится, пока использование остаётся высоким: здесь вернулись те же токены, но в других случаях, чтобы его снизить, нужны новые вкладчики или погашения, которых привлекает высокая ставка.

Ставку по займу меняют ещё две вещи. Governance или Risk Stewards могут изменить четыре параметра, и тогда сдвигается сразу вся кривая. А между транзакциями ставка не меняется: Aave пересчитывает её при каждом внесении, заёме, погашении, выводе и ликвидации этого актива, и проценты начисляются по этой ставке, секунда за секундой, до следующего пересчёта.

## Почему вкладчики получают меньше, чем платят заёмщики?

Вкладчики получают меньше, чем платят заёмщики, потому что проценты платит только занятая часть пула, а протокол оставляет себе их долю. Ставка по вкладу:

**Ставка по вкладу = ставка по займу × использование × (1 − резервный коэффициент)**

Для USDC на Ethereum Core 25 октября 2026 г.: 4,4866 % × 0,9372 × (1 − 0,10) = 3,78 %. Резервный коэффициент, 10 % для USDC и 15 % для WETH, идёт в казну Aave. Если у резерва есть дефицит из-за безнадёжного долга (bad debt), контракт также учитывает его на стороне вкладов, и это немного снижает ставку по вкладу.

## Чем APR отличается от APY на Aave?

Контракты хранят ставки в виде APR, а приложение Aave показывает APY, где учтено начисление сложных процентов. Математическая библиотека приложения капитализирует APR каждую секунду в течение года из 31 536 000 секунд:

**APY = (1 + APR ÷ 31 536 000)^(31 536 000) − 1**

APR 4,4866 % для USDC на Ethereum Core отображается в приложении как APY 4,59 %. На таких уровнях разница составляет около десятой доли пункта; при APR 14 % она около одного пункта (APY 15,0 %).

## Как скачки ставок влияют на ваш health factor?

Короткий скачок почти не сдвигает ваш health factor (фактор здоровья); высокая ставка, которая держится месяцами, сдвигает. Проценты добавляются к вашему долгу, а больший долг снижает health factor, как объясняет [причина с процентами в руководстве о том, почему падает health factor](/ru/blog/pochemu-upal-health-factor-aave#причина-3-начислялись-ли-проценты-по-долгу-быстрее-чем-по-залогу).

Возьмём 10 WETH, внесённых под заём 12 000 USDC на Ethereum Core, с порогом ликвидации WETH 83 % (данные на 14 октября 2026 г.) и условной ценой ETH 2 400 $: health factor равен 1,66. С учётом того, что WETH приносит по своей ставке по вкладу 1,31 %:

| Как долго держится ставка | При 4,49 % (25 октября 2026 г.) | При 14,50 % (верх кривой) |
| ------------------------- | ------------------------------- | ------------------------- |
| 36 минут                  | около 0,04 USDC процентов, 1,66 | около 0,12 USDC, 1,66     |
| 30 дней                   | около 1,66                      | около 1,64                |
| Один год                  | около 1,61                      | около 1,45                |

Скачок 14 октября обошёлся этой позиции примерно в 12 центов. Рынок, который целый год стоит на вершине своей кривой, опустил бы её health factor с 1,66 примерно до 1,45 без всякого движения цены, поэтому из-за медленного дрейфа порог оповещения стоит выбирать с запасом ([какой запас даёт health factor](/ru/blog/bezopasnyy-health-factor-aave#как-быстро-проценты-и-изменения-параметров-съедают-ваш-запас)).

## Что делать, если ставка по вашему займу подскочила?

Когда ставка по вашему займу подскочила, сначала проверьте коэффициент использования актива на его странице в приложении Aave: если он чуть выше оптимального, ставка снова упадёт, как только снизится использование. Дальше у вас четыре варианта, и у каждого своя цена:

- **Подождать.** Скачок, вызванный одним крупным выводом, может закончиться, когда эти токены вернутся, как 14 октября 2026 г. Ничто не гарантирует, что они вернутся, а тем временем вы платите высокую ставку.
- **Погасить часть долга.** Это снижает и ваши проценты, и ваш риск; руководство [как поднять health factor на Aave](/ru/blog/kak-izbezhat-likvidatsii-na-aave) рассказывает о погашении своими токенами или залогом.
- **Перевести долг в другой актив.** В интерфейсе Aave Labs есть debt swap (обмен долга), который за одну транзакцию заменяет один занятый актив другим, на рынках Ethereum Core, Prime и EtherFi и в сетях Arbitrum, Avalanche, Base, BNB Chain, Optimism, Polygon, Gnosis и Sonic, согласно документации Aave. Для Metis, Scroll, ZKsync, Celo, Soneium, Linea, Plasma и Ink он не указан. У нового актива своя кривая и свой риск, если его цена движется иначе, чем ваш прежний долг.
- **Занять на другом рынке.** У каждого рынка свой пул и своё использование: 25 октября 2026 г. USDC стоил 4,49 % на Ethereum Core и 3,44 % на Arbitrum. Переезд означает погашение на одном рынке и заём на другом, с залогом в той сети.

## Как устанавливаются ставки для GHO и на Aave V4?

У GHO, собственного стейблкоина (stablecoin) Aave, постоянная ставка по займу, которую выбирают люди, а не кривая. На Ethereum Core оба наклона в его параметрах равны нулю, поэтому ставка равна базовой: 4,50 % на 25 октября 2026 г. Её меняет Risk Council, которому нужны 2 подписи из 3, через контракт GHO steward: не более чем на 5 процентных пунктов за одно обновление и не чаще раза в день. Последнее изменение, 3 октября 2026 г., подняло её с 4,25 % до 4,50 %; с ноября 2024 г. её меняли 44 раза, в диапазоне от 3,00 % до 14,50 %. Прежняя скидка для держателей stkAAVE была отменена в Aave v3.4.

Aave V4 сохраняет кривую использования, но документация описывает её как настраиваемую для каждого актива в Hub, пуле, который кредитует все Spoke. Поверх этой общей ставки каждый заёмщик платит User Risk Premium, которая зависит от качества его залога: в примере Aave премия 50 % к базовой ставке 5 % даёт 7,5 %. Поэтому два заёмщика одного актива в V4 могут платить разные ставки, а о том, что ещё меняет V4, рассказывает [раздел о V4 в руководстве по health factor](/ru/blog/aave-health-factor-obyasnenie#отличается-ли-health-factor-в-aave-v4).

## Можно ли получить фиксированную ставку на Aave?

Нет. Когда-то в Aave V3 был вариант со стабильной ставкой (stable rate), но в 2024 г. после сообщения об ошибке от него полностью отказались, а Aave v3.2 удалила этот код. Каждый заём в Aave V3 идёт под переменную ставку, а постоянную ставку GHO в любой момент можно изменить в пределах полномочий его steward.

## Может ли оповещение предупредить о росте ставок?

Оповещение о health factor не следит за ставками; оно следит за тем, что ставки делают с вашей позицией. Tokenping проверяет ваш health factor в Aave V3 и V4 каждые 5 минут в 22 сетях и пишет вам в Signal, Telegram или на email, пока он ниже заданного вами порога (от 1,1 до 10). Скачок вроде того, что был 14 октября 2026 г., оповещение не вызовет, потому что почти не сдвигает health factor; месяцы высоких процентов вызовут, как только долг вырастет настолько, что пересечёт ваш порог.

Если вам нужно сообщение о самой ставке, некоторые другие инструменты присылают оповещения о ставках, а [наше сравнение инструментов оповещений для Aave](/ru/blog/instrumenty-opoveshcheniy-o-likvidatsii-aave) показывает, за чем следит каждый из них. Настройка оповещения о health factor описана в руководстве [как настроить оповещение о health factor](/ru/blog/nastroyka-opoveshcheniy-health-factor-aave), а сначала вы можете [проверить свой health factor в Aave V3](/ru/aave); чтобы посмотреть свои позиции, платить не нужно.
