## Что такое предликвидация на Morpho?

Предликвидация это вторая, более ранняя черта ликвидации, которую заёмщик может добавить на одном рынке Morpho Blue. На обычном рынке Blue позицию можно ликвидировать, только когда её health factor (фактор здоровья), измеренный относительно ликвидационного отношения займа к стоимости залога (LLTV) рынка, опускается ниже 1; это число объясняет [руководство по health factor на Morpho](/ru/blog/morpho-health-factor-obyasnenie). Контракт предликвидации задаёт более низкую черту, preLLTV. Между двумя чертами кто угодно может по шагам погашать часть вашего долга, в пределах лимита, заданного контрактом, и забирать залог на сумму этого долга плюс бонус.

Её отличают три вещи:

- **Она включается по желанию.** Она действует, только после того как вы разрешите контракт в Morpho Blue. Без этого контракт не может затронуть вашу позицию.
- **Она привязана к рынку.** Каждый контракт связан с одним рынком Blue и одним неизменным набором параметров, и у него нет владельца, администратора или функции обновления.
- **Она есть только в Blue.** В Morpho Midnight, рынках с фиксированной ставкой из [руководства по Midnight](/ru/blog/morpho-midnight-zaymy-s-fiksirovannoy-stavkoy), предликвидации нет.

Morpho объявил о фабрике предликвидации 4 марта 2025 г. и назвал в качестве её применений auto-deleverage и auto-close. В контрактах, API и SDK она называется pre-liquidation. В приложении Morpho была функция Auto-deleverage, которую справочный центр описывает теми же словами: как только отношение займа к стоимости залога превышает заданный порог, часть позиции может быть закрыта, а комиссия берётся только с закрытой части.

## Доступна ли ещё предликвидация в приложении Morpho?

Новую предликвидацию в приложении Morpho настроить нельзя. По состоянию на 26 октября 2026 г.:

| Где                                  | Состояние                                                                                                                                                                                                                                 |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Приложение Morpho и справочный центр | Справочная статья теперь называется «Sunsetting Auto-deleverage» («Сворачивание Auto-deleverage»), последнее обновление 13 мая 2026 г.: функция не принимает новых позиций, а пользователям, у которых она включена, следует её отключить |
| SDK Morpho                           | Все экспорты предликвидации помечены как устаревшие 22 сентября 2026 г. (pull request 1132), будут удалены в следующей мажорной версии, замены нет                                                                                        |
| Документация Morpho                  | Страницы о предликвидации больше нет; её старый адрес теперь ведёт на общую страницу о ликвидации                                                                                                                                         |
| API Morpho                           | По-прежнему указывает 106 контрактов предликвидации на рынках из списка в Ethereum (50), Base (37), Arbitrum (8), Polygon (6), Katana (3) и Unichain (2)                                                                                  |
| Контракты                            | Не изменились и работают: кто угодно по-прежнему может вызвать их для заёмщика, который их разрешил                                                                                                                                       |

Если вы включали функцию раньше, важна последняя строка. Сворачивание функции в приложении не отменяет разрешение, записанное в блокчейне.

## Как работает контракт предликвидации?

Контракт предликвидации создаёт PreLiquidationFactory от Morpho, которой может пользоваться кто угодно: любой может развернуть контракт для любого рынка Blue, а каждая комбинация рынка и набора параметров может существовать только один раз. Его неизменные параметры:

| Параметр         | Что он задаёт                                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| preLLTV          | Отношение займа к стоимости залога, выше которого разрешена предликвидация. Должно быть ниже LLTV рынка                                                |
| preLCF1, preLCF2 | Close factor: наибольшая доля вашего долга, которую может погасить один вызов, на уровне preLLTV и на уровне LLTV                                      |
| preLIF1, preLIF2 | Коэффициент вознаграждения: на него умножается погашенный долг, чтобы получить изымаемый залог, в тех же двух точках                                   |
| Оракул           | Источник цены, который решает, можно ли вас предликвидировать и по какой цене забирается ваш залог. Это может быть собственный оракул рынка или другой |

Прежде чем действовать, контракт по цене своего оракула проверяет, что ваше отношение займа к стоимости залога выше preLLTV и при этом не выше LLTV. Выше LLTV предликвидация прекращается, и в силу вступает обычная ликвидация Blue. После этого Morpho Blue проверяет по собственному оракулу рынка, что ваша позиция здорова; если нет, весь вызов отменяется.

Конструктор ограничивает параметры. Close factor не может уменьшаться с ростом риска, а пределом 100 % ограничено только его первое значение: контракт, у которого второе значение выше 100 %, может позволить одному вызову погасить весь ваш долг ещё до LLTV. Значения Morpho по умолчанию намного ниже этого. Коэффициент вознаграждения должен быть не меньше 1 (без бонуса) и не больше 1 ÷ LLTV (бонус около 16 % на рынке с LLTV 86 %). В репозитории Morpho сказано, что этот предел вместе с правилом, по которому предликвидация прекращается на LLTV, не даёт предликвидации оставить позицию менее здоровой, чем до неё.

### Как растут close factor и бонус между preLLTV и LLTV?

Оба растут линейно вместе с вашим отношением займа к стоимости залога. Контракт измеряет, насколько далеко вы продвинулись от preLLTV к LLTV, в виде доли от 0 до 1, и сдвигает каждый коэффициент на эту долю пути от первого значения ко второму. На полпути между двумя чертами close factor находится на полпути между preLCF1 и preLCF2.

Из кода следуют два ограничения. Close factor ограничивает один вызов, а не общий объём: собственный репозиторий Morpho отмечает, что ликвидатор может закрыть небольшую часть, оставив вас всё ещё выше preLLTV, и вызвать контракт снова, так что всего может быть закрыто больше, чем close factor. Кроме того, close factor это доля вашего долга, а не залога; та же идея на Aave разобрана в [руководстве Aave о close factor](/ru/blog/kak-rabotaet-likvidatsiya-na-aave#какую-часть-долга-могут-ликвидировать-за-один-раз).

У крупнейшего по объёму займов рынка Blue из списка в Base, USDC | cbBTC (86%) (залог cbBTC, долг в USDC, LLTV 86 %), есть один контракт предликвидации, указанный в API Morpho, по адресу `0xa7272aFc21f9C321024ED93892a1abfeb621C374`. Данные прочитаны из Base 26 октября 2026 г. и сверены с API Morpho:

- PreLiquidationFactory в Base подтверждает, что создала этот контракт, а контракт указывает на этот рынок.
- preLLTV 83,26 %, close factor растёт от 0,20 % до 24,53 %, бонус 4,38 % на обоих концах: значения по умолчанию для 86 %.
- Его оракул это собственный оракул рынка. В блоках Base 53102870 и 53102952 он оценивал cbBTC в 80 000,15 USDC; руководство [как работает ликвидация на Morpho](/ru/blog/kak-rabotaet-likvidatsiya-na-morpho) использует ту же цену.
- На рынке было занято около 1,61 млрд USDC под залог около 40 051 cbBTC, примерно в 43 000 заёмных позиций.
- В примерно 28 часах блоков Base, прочитанных до блока 53102692, не нашлось ни одной предликвидации через этот контракт.

## Пример расчёта: сколько может забрать одна предликвидация?

Возьмём условную позицию на этом рынке Base: 1 cbBTC в залоге и 50 000 USDC долга при цене 80 000,15 USDC за cbBTC. Её health factor равен 1,376 относительно LLTV 86 % и 1,332 относительно черты предликвидации 83,26 %. При том же оракуле значение для предликвидации всегда равно значению для рынка, умноженному на 0,968 (83,26 ÷ 86).

Предликвидация может начаться, как только cbBTC опустится ниже 60 052,58 USDC, на 24,9 % ниже этой цены. Обычная ликвидация начинается ниже 58 139,53 USDC, на 27,3 % ниже. Между этими ценами самая крупная одиночная предликвидация выглядит так:

| ---------------------------------- | ---------- | ------------ | -------------- | ----------------------- | ----- | ---------------------------------------- |

При значениях по умолчанию один вызов полного размера возвращает отношение займа к стоимости залога примерно к preLLTV, где контракт останавливается. Сравните с обычной ликвидацией Blue при 87 %: ликвидатор может погасить все 50 000 USDC и забрать cbBTC на 52 192 USDC, оставив вам около 5 279 USDC залога и никакого займа.

## Почему заёмщики включали предликвидацию и во что она им обходилась?

Довод в пользу включения: продажи меньше и постепенно. Справочная статья Morpho описывает Auto-deleverage как закрытие только части позиции, чтобы восстановить её здоровье, с комиссией только с закрытой суммы. В примере выше заёмщик, включивший функцию, платил на каждом шаге от 148 до 538 USDC бонуса, тогда как обычная ликвидация при 87 %, погашающая весь заём, стоит 2 192 USDC; несколько шагов или обычная ликвидация после них в сумме могут обойтись дороже.

Издержки:

- **Продажи начинаются раньше.** На рынке с LLTV 86 % часть вашей позиции можно продать начиная с health factor рынка около 1,033, когда health factor, который описывает справочный центр Morpho и который измеряется относительно LLTV, ещё выше 1.
- **Шаги могут повторяться.** Close factor ограничивает каждый вызов, а не общий объём, поэтому, пока вы остаётесь выше preLLTV, несколько вызовов могут следовать один за другим.
- **Цена может отличаться.** Контракт может использовать оракул, отличный от оракула рынка. Все 106 контрактов, указанных в API Morpho, используют собственный оракул своего рынка; контракт, которого нет в списке, может этого не делать.
- **Никто не обязан действовать.** Если ни один ликвидатор не вызовет контракт, до LLTV ничего не произойдёт; как только вы его пересечёте, вас могут ликвидировать обычным способом.

Теперь, когда функцию сворачивают, Morpho просит заёмщиков, у которых она ещё включена, отключить её, а новые подключения закрыты.

## Как проверить, разрешили ли вы такой контракт?

Вы разрешили контракт предликвидации, если `isAuthorized(ваш кошелёк, контракт)` в Morpho Blue возвращает true. Разрешение хранится в самом Morpho Blue, а не в контракте предликвидации.

1. **Найдите контракт для своего рынка.** API Morpho указывает его среди предликвидаций рынка; справочный центр Morpho также указывает на кнопку управления на странице вашей позиции или рынка в приложении.
2. **Вызовите `isAuthorized` в контракте Morpho Blue этой сети.** В обозревателе блоков откройте функции чтения контракта Blue и введите свой кошелёк первым адресом, а контракт предликвидации вторым.
3. **Прочитайте ответ.** True означает, что контракт может вас предликвидировать; false означает, что не может.

Для этих шагов нужен адрес контракта, а API Morpho указывает только контракты с настройками по умолчанию. Разрешение также можно выдать подписью, которую отправит кто-то другой, поэтому оно может не отображаться в собственном списке транзакций вашего кошелька. Чтобы увидеть все адреса, которым вы дали разрешение, посмотрите в обозревателе блоков события SetAuthorization контракта Morpho Blue, где ваш кошелёк указан как authorizer. Последнее событие для каждого адреса показывает, действует ли разрешение, а PreLiquidationFactory сети отвечает true на `isPreLiquidation(address)` для созданных ею контрактов.

Здесь важна одна деталь. В разрешении Blue нет рынка: адрес, который вы разрешили, проходит проверки Blue для ваших займов, выводов и выводов залога во всём этом контракте Blue. Неизменный код контракта предликвидации только гасит долг и выводит залог на своём рынке, но другие разрешённые вами адреса так не ограничены.

## Как отключить предликвидацию?

Чтобы её отключить, верните разрешению значение false:

- **В приложении Morpho:** справочный центр Morpho советует нажать кнопку управления у позиции на вашей панели или на странице рынка; откроется окно удаления Auto-deleverage.
- **В контракте:** вызовите `setAuthorization(контракт предликвидации, false)` в Morpho Blue со своего кошелька. Вызов не проходит, если значение уже false, поэтому неудачный вызов может означать и то, что удалять было нечего.

После отзыва попытки контракта вывести ваш залог не проходят, и действует только обычная ликвидация Blue ниже health factor 1. Это стоит газа одной транзакции.

## Как Tokenping измеряет позицию с предликвидацией?

Для заёмщика, который разрешил контракт предликвидации на рынке Blue, Tokenping отправляет оповещения по более низкой из двух черт: черты LLTV и черты предликвидации. Это важно, потому что справочный центр Morpho описывает health factor в своём приложении как достигающий 1, когда отношение займа к стоимости залога превышает LLTV, а именно там начинается и собственная ликвидация Blue. На рынке с LLTV 86 % и контрактом по умолчанию порог оповещения 1,10 по черте предликвидации срабатывает при health factor рынка около 1,136, а самый низкий порог, 1,02, срабатывает примерно при 1,054, примерно на 2 % выше черты, где может начаться предликвидация.

Когда вы сохраняете или редактируете оповещение, Tokenping отмечает контракты предликвидации, которые API Morpho указывает для этого рынка; затем каждая проверка читает, разрешили ли вы каждый из них, и считает health factor по данным блокчейна с помощью собственной математики Morpho, никогда не по API Morpho. Контракт предликвидации, которого нет в API Morpho, не проверяется, поэтому, если вы разрешили контракт с нестандартными настройками, оповещение измеряет позицию только относительно черты LLTV.

Остальное работает так же, как для любого оповещения Morpho. Tokenping проверяет каждые 5 минут, в 14 сетях, и, пока ваш health factor ниже вашего порога (любое значение от 1,02 до 10), каждая проверка отправляет сообщение по каждому выбранному каналу: Signal, Telegram или email. Оповещения стоят <AlertPrice />, это тот же план, что и для оповещений Aave, а чтобы [посмотреть свои позиции на Morpho](/ru/morpho), платить не нужно. Руководство [как выбрать порог оповещения](/ru/blog/bezopasnyy-health-factor-aave#как-выбрать-порог-оповещения-шаг-за-шагом) разбирает этот компромисс на Aave; здесь применимы те же соображения. Оповещение даёт вам время действовать, а не гарантию: цена может измениться между двумя проверками. Если предликвидация вам больше не нужна, отзовите её, как показано выше; после этого оповещение измеряет позицию только относительно черты LLTV.
